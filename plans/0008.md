# 0008 — libp2p relay + rendezvous (fallback signaling)

| Field | Value |

## Summary

libp2p circuit relay v2 + rendezvous discovery when WebTorrent trackers are unavailable. Peers register on `vibe/conv/{conversationId}`, connect via community bootstrap relays, and exchange encrypted SDP over gossipsub.

## Changes

- [`bootstrap.rs`](../src-tauri/src/bootstrap.rs) — community relay/rendezvous peer multiaddrs
- [`network.rs`](../src-tauri/src/network.rs) — relay client, rendezvous client, per-conversation register/discover

## When used

[`signaling.ts`](../src/lib/transport/signaling.ts) tries tracker tunnel first ([0009](0009.md)), then libp2p gossipsub if the contact is a connected overlay peer.

## Manual test

1. Block WebSocket trackers (firewall / offline wss)
2. Open chat on both devices with libp2p bootstrap reachable
3. Overlay connects → gossipsub SDP → WebRTC
